# Content rating (IARC) — anketaga javoblar

Play Console → **App content → Content rating**

---

## Kategoriya tanlash

**Game** → keyingi savollarga o'ting.

---

## Anketa javoblari

Hammasi **No** / **Yo'q** — bu oddiy taxta o'yini.

| Savol | Javob |
|---|---|
| Violence — Does the app contain violence? | No |
| Violence — Realistic violence towards human/animal characters? | No |
| Sexuality — Sexual content or nudity? | No |
| Language — Profanity or crude humour? | No |
| Controlled substances — Drugs, alcohol, tobacco? | No |
| Gambling — Simulated gambling or real-money gambling? | No |
| Gambling — Does the app allow users to purchase virtual currency? | No |
| Miscellaneous — Does the app share the user's location? | No |
| Miscellaneous — Does the app allow users to interact or exchange content? | No |
| Miscellaneous — Does the app allow purchase of digital goods? | No |
| Miscellaneous — Does the app contain user-generated content? | No |
| Miscellaneous — Does the app have a native ad or sponsored content? | No |
| Miscellaneous — Horror/fear themes? | No |

### "Does the app allow users to interact?" haqida

Javob **No**: ilovada chat, forum, ko'p o'yinchi rejimi yoki boshqa
foydalanuvchilar bilan aloqa yo'q. Siz faqat qurilmadagi neyron tarmoq
bilan o'ynaysiz.

## Target audience and content

Play Console → **App content → Target audience and content**

| Savol | Tavsiya etilgan javob |
|---|---|
| Target age groups | **13–15, 16–17, 18+** |
| Appeal to children | No |
| Store listing for families | Yo'q |

> 13 yoshdan kichik guruhlarni ham belgilashingiz mumkin — ilova
> Families siyosatining mazmunan barcha talablariga javob beradi
> (reklama yo'q, ma'lumot yig'ilmaydi, tashqi havola yo'q, xarid yo'q).
> Lekin u holda qo'shimcha anketa to'ldiriladi va tekshiruv uzayadi.
> Birinchi relizda 13+ bilan boshlash soddaroq; keyinroq o'zgartirish
